THE WORLD IN A DAY: a broadcast-style front page summing up Saturday 21 November 2026 in one image. A full-width cinematic lead panel draws a seismograph trace for the Peru 6.8 earthquake; below it, four stories in one row (the Rikers Island closure plan, record foreign investment into India, Anthropic's post-IPO slide, the Palisades Fire verdict) and a red ticker strip of briefs (Nepal's PM, the Austria hack, Kuno's cheetah cubs, India's women's hockey). Pure Python 3 standard library, no network, fully deterministic: the same run always writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes the front page to `out/entry.png` (1024 x 1024 PNG).
